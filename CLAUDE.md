# Repository Guidelines

- Write docstrings for public modules, classes, and functions.
- Follow best practices — DRY, YAGNI, low coupling — over clever or premature abstraction.
- Use Conventional Commits for commit messages (e.g. `feat:`, `fix:`, `docs:`, `refactor:`).
- When behavior changes, update the affected docs (`README.md`, `docs/`) to match. Keep updates concise.
