# Slide

Reads pixel data from a whole slide image. `Slide` only knows how to read pixels - see
[`tissue_mask`](tissue.md), [`tile_regions`](tiles.md) and
[`export_tiles`](export.md) for tissue detection, tile grids and saving.

`SlideReader` is kept as a deprecated alias for `Slide`.
