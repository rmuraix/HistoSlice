# slice_slide

The high-level, one-call convenience function - reads a slide, detects tissue,
generates a tile grid, filters by tissue content, and exports tiles. See
[`Slide`](slide.md), [`tissue_mask`](tissue.md), [`tile_regions`/`filter_by_tissue`](tiles.md)
and [`export_tiles`](export.md) if you need control over an individual step instead.
